# Documentation and Phrasebank Generation Facts

- Public user guides live under `academic-phrasebank-skill/docs/`. The release builder copies the complete skill directory, so links from the root README to those guides remain valid in source checkouts and user archives.
- Phrasebank page files, `references/index.md`, and `references/source-coverage.md` are generated by `tools/build_phrasebank_refs.py`. Changes to their shared structure must be made in the builder and regenerated; hand edits to phrase lines will be overwritten and break source reproducibility.
- `references/revision-framework.md` is hand-maintained and explicitly preserved during the reference directory swap. It must stay outside generated output.
- The live builder fetches current sitemap snapshots. A rebuild can introduce upstream-only changes in `data/raw/` even when the requested change is documentation-only; inspect the diff and keep unrelated raw snapshot churn out of a focused documentation change.
- Generated reference pages now expose a common route, input, output, boundary, and source block before the upstream summary and phrase groups. This gives both readers and models an explicit safety boundary without changing the upstream phrase text.
